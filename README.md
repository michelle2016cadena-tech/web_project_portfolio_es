# web_project_potrfolio_es

## Descripcion breve del proyecto
Portafolio web profesional de Erika Cadena, desarrolladora web especializada en HTML, CSS y JavaScript. La interfaz presenta un diseño moderno y elegante con una paleta de colores oscuros y detalles luminosos, destacando una fotografía profesional, una sección de habilidades técnicas y un apartado de proyectos desarrollados. El sitio está diseñado para mostrar experiencia en la creación de interfaces web limpias, responsivas y funcionales, además de facilitar el contacto profesional a través de diferentes canales digitales.

## Tecnologias Usadas
* HTML5
* CSS3
* JavaScript
